# VisionGuard AI

A real-time computer vision project built using Python, OpenCV, and YOLOv8.

## Features

- Real-time webcam detection
- Person detection
- Person counter
- Confidence filtering
- Edge AI ready architecture (Work in Progress)

## Technologies

- Python
- OpenCV
- YOLOv8 (Ultralytics)
